# Experiments

Experiments are governed investigations of models, context, caching, routing, runtimes and optimisation techniques. They retain successful, negative and boundary results so that a useful hypothesis does not silently become a product claim.

Agent Control remains responsible for execution, authority, telemetry and evidence. Lab stores experiment definitions and reproducible projections over that evidence; it is not a second execution engine.

An experiment contribution should state:

- its question and falsifiable outcome;
- fixed and changed variables;
- hardware, model and runtime identity requirements;
- repetitions and telemetry authority;
- verification criteria;
- safety and resource limits;
- the evidence and report-generation path.

The first published worked example is the [P5000 × Qwen3.8-27B configuration comparison](../reports/p5000-qwen3.8-27b/report.md). Additional experiment definitions will be added without changing the existing Jobs contract.
