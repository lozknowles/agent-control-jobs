# Agent Template native qualification — 20 September 2026

## Scope and status

Agent Control executed the five allow-listed Lab Jobs through Work Parcel, Job Runtime, the adaptive harness model action and an independent control-step verifier. The final matched suite contains 34 runs on the existing `qwen2.5-3b-instruct-q4_k_m.gguf` backend. No model was downloaded, and no service was restarted or reconfigured.

The result is negative: **0/34 outputs passed the exact hidden acceptance oracle**. All 34 final-suite model invocations completed and were independently checked, so this is behavioural evidence rather than an executor or prerequisite block. It does not establish that any specialist template improves model effectiveness.

The earlier 34-run suite is retained as `2026-09-20-qwen25-3b-initial-contract.json`. It also produced no acceptance passes; one plain model-evaluator call had a provider transport failure. Its scenarios did not prescribe fact field names, so it is retained as negative evidence but is not used for the comparison below. The final suite prescribed output keys without disclosing answer values.

Small, mostly deterministic samples on one 3B quantized model do not support broader claims.

## Limitations

- Only the existing local Qwen 2.5 3B quantized backend was tested.
- Primary cases have three repetitions per arm; clean and documentation-agreement controls have one. This is insufficient for statistical effectiveness claims.
- No dashboard Agent Templates workflow was implemented or tested. Lab catalogue CLI and Agent Control API/runtime paths are implemented.
- `source-comparison`, `repository-health-audit`, `structured-extraction` and `benchmark-model` remain compatible template declarations without native adapters in this candidate.
- Live connectors, paid providers, provider adaptations, multiple models, remote workers and cancellation during an in-flight model request were not physically exercised.
